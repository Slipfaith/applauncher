# Предложения по улучшению AppLauncher

На основе анализа репозитория были выявлены ключевые области для улучшения стабильности, производительности и удобства использования.

## 1. Стабильность горячих клавиш (Hotkey)
**Проблема:** Использование библиотек `keyboard` или `pynput` на базе хуков ввода делает горячие клавиши нестабильными (они отключаются системой при конфликтах привилегий или таймаутах).
**Решение:**
- Перейти на **Native Windows API (`RegisterHotKey`)** через `ctypes` или `win32gui`. Это системный механизм регистрации, который не блокируется ОС и работает в фоновом режиме надежнее хуков.
- Реализовать механизм автоматической перерегистрации при выходе из спящего режима или смене сессии пользователя.

## 2. Управление конфигурацией и данными
**Проблема:** Ручная валидация словарей в `config.py` усложняет расширение настроек.
**Решение:**
- Внедрить **Pydantic** для описания моделей данных. Это обеспечит строгую типизацию, автоматическую валидацию JSON и упростит работу с вложенными структурами (группы, приложения, заметки).
- Добавить поддержку **Portable mode**: если в папке с `.exe` есть файл `portable.txt`, сохранять настройки там же, а не в `%APPDATA%`.

## 3. Производительность и UI
**Проблема:** Извлечение иконок и загрузка больших списков могут блокировать основной поток GUI.
**Решение:**
- Вынести тяжелые операции (извлечение иконок из `.exe`, работа с файловой системой) в **QThread** или использовать `asyncio` для сетевых запросов.
- Реализовать **ленивую загрузку (Lazy Loading)** для иконок в сетке приложений: загружать изображения только тогда, когда они становятся видимыми на экране.

## 4. Новые функции
- **Очистка кэша в один клик:** Добавить в диалог настроек кнопку "Очистить кэш иконок" и "Сбросить настройки", чтобы пользователю не приходилось искать папку в `AppData`.
- **Передача аргументов:** Улучшить механизм `Single Instance` через `QLocalServer`, чтобы при повторном запуске программы с аргументом (например, `app.exe "C:\path	o\file"`) этот файл автоматически добавлялся в текущую открытую вкладку лаунчера.
- **Авто-категории:** Добавить базовую логику автоматического распределения приложений по группам (Игры, Работа, Системные) на основе метаданных или путей.

## 5. Качество кода (QA)
- Добавить **Unit-тесты** для `LaunchService` и `SearchService`, чтобы гарантировать корректность запуска различных типов файлов (url, lnk, bat).
- Настроить **CI/CD (GitHub Actions)** для автоматической сборки `.exe` через PyInstaller при каждом релизе.
