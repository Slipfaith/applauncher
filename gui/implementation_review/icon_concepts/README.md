# Варианты стандартных иконок

Предпросмотр `fallback_icons_variants_v1.png` создан встроенным imagegen для выбора перед внедрением. В строках три направления: 01 LINE — контур, 02 SOFT — мягкий объём, 03 DUO — двухцветные формы. Столбцы: папка, ссылка, программа без своей иконки; слева светлая тема, справа тёмная.

Пользователь выбрал **01 LINE** после просмотра. Набор реализован в `applauncher/gui/fallback_icons.py` с помощью векторных контуров QPainter. Это точная масштабируемая отрисовка направления LINE, а не вырезки из концептуального изображения. Фактический результат показан в `line01_implemented.png`; прозрачные PNG на двух темах экспортируются рядом с этим файлом. Реализация используется в плитках, списке, панели горячих клавиш и универсальном поиске, когда собственная картинка недоступна.
