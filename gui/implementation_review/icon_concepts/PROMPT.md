# Промпт предпросмотра

Инструмент: встроенный imagegen. Результат: `fallback_icons_variants_v1.png`.

Use case: ui-mockup / stylized-concept. Asset type: ONE professional icon-design comparison contact sheet, preview only, for a compact Windows desktop app launcher with custom modern fallback icons. Render a polished landscape design board. Three numbered horizontal rows, exact concise row labels '01  LINE', '02  SOFT', '03  DUO'. Each row contains a coherent set of THREE original icons: folder, website link, application without an icon. Repeat that SAME set on a pale cool background #f3f5fa at left and a deep navy background #0b1020 at right. Column headers exactly 'FOLDER', 'LINK', 'APP'. Row 01 LINE: crisp premium rounded outline icons, confident 2.5 px-equivalent strokes, blue accent, clear folder silhouette, two interlocking chain links for URL, rounded application-window with simple four-square grid. Row 02 SOFT: tasteful small sculpted 3D icons with subtle luminous cobalt/azure material, restrained depth and soft highlights, simple open folder, interlocking links, rounded app tile or app-window with grid; excellent legibility at small sizes, no excessive detail. Row 03 DUO: refined geometric filled duotone icons, layered cyan/cobalt surfaces, small negative-space cutouts, flat front-facing shapes with slight depth, same folder/chain/application meanings. Each icon must feel like part of its row's unified family. Every sample is isolated with generous spacing, rendered around 64 px in visual scale, no enclosing button/background squares except where the application's own silhouette needs it. All three icons have equal perceived size. Aim for calm polished current desktop aesthetic; do not use emojis, existing brand logos, generic globe icons, text inside icons, ornamental sparkles, illustration scenes, device mockups or fake screenshots. Display only comparison board, no rendered app UI and no watermarks. Make both theme columns equally clear. Original custom shapes, crisp and intentional.
