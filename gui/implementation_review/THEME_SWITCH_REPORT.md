# Переключатель темы в настройках

После этого этапа пользователь выбрал иконки 01 LINE. Их внедрение и текущая сборка описаны в `LINE01_REPORT.md`; приведённый ниже хеш относится к сборке с переключателем темы до добавления LINE. Актуальный хеш — в `final_integrity.json`.

Реализован по отдельному запросу пользователя после основного переноса интерфейса. Первоначальный план исключал ручной выбор; новый запрос добавляет его в согласованный объём.

В начале «Настройки» находится поле «Тема оформления» с режимами «Автоматически», «Светлая», «Тёмная». Выбор сразу применяется к QApplication: оболочке главного окна, диалогам, меню, поиску, заметкам, истории буфера и нарисованным значкам. Qt 6.8+ также получает подсказку о выбранной схеме для системного оформления окон. В автоматическом режиме приложение возвращается к теме Windows и отслеживает дальнейшие изменения.

В конфигурации сохраняется `theme_mode` со значениями `auto`, `light`, `dark`. При запуске режим применяется до показа окна. Старые файлы и некорректное значение используют `auto`; миграция не требуется. Сброс настроек возвращает автоматический режим и обновляет поле в уже открытом окне настроек.

Переключение не пересоздаёт плитки и документы. Проверены сохранение поиска, положения прокрутки, текста, выделения и истории отмены открытого редактора. Пользовательские картинки и явно выбранные цвета текста сохраняются. Подписи плиток используют ограниченный кэш по тексту/шрифту/размеру, чтобы при изменении палитры повторно не рассчитывать перенос. Обработчик изменения размера окна пропускает посторонние события; одинаковая таблица стилей повторно не применяется.
